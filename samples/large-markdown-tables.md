# 내용이 많은 마크다운 표 샘플

가상의 문서 편집기 검토 자료입니다. 긴 문장 표, 120행의 작업 목록, 특수한 셀 내용으로 구성되어 있습니다.

창 크기와 열 너비를 바꿔 보고, 긴 셀의 내용을 짧게 고쳐 보세요. 표 아래 본문이 셀 높이에 맞춰 이동하는지도 살펴볼 수 있습니다.

## 긴 문장과 행 높이

| 항목 | 내용 |
| :--- | :--- |
| 파일 열기 | 여러 문서를 한 번에 열었을 때 각 문서의 제목과 내용이 올바른 탭에 표시되는지 확인합니다. 이미 열린 파일을 다시 선택하면 기존 탭으로 이동하고, 편집 중인 내용은 그대로 유지합니다. 같은 단어가 본문과 여러 표에 반복되어 있을 때 검색 결과를 이동하며 현재 위치를 확인합니다. |
| 한글 입력 | 문장 중간에서 한글을 입력하고 지운 뒤 조합 중인 글자와 커서 위치가 자연스럽게 유지되는지 확인합니다. 짧은 단어, 긴 문장, 숫자와 영문이 섞인 내용을 차례로 입력합니다. 긴 문장의 앞부분부터 여러 줄에 걸쳐 선택한 다음 복사한 내용이 원문과 같은지 확인합니다.<br><br>두 번째 문단입니다. 빈 줄도 셀 안의 높이에 포함되어야 합니다. |
| 표 편집 | 내용이 긴 셀과 짧은 셀을 같은 행에 배치한 뒤 가장 높은 셀에 맞춰 행 전체가 늘어나는지 확인합니다. 열 너비를 줄였다가 넓히고, 긴 내용을 삭제했을 때 높이가 다시 줄어드는지도 확인합니다. 같은 셀에 이어서 입력한 내용을 되돌린 뒤 다시 실행하여 원래 문장과 선택 위치가 복원되는지 확인합니다. |
| 문서 검색 | 같은 단어가 본문과 여러 표에 반복되어 있을 때 검색 결과를 이동하며 현재 위치를 확인합니다. 첫 번째 결과부터 마지막 결과까지 이동하고 검색창을 닫은 뒤 입력을 이어 갑니다. 창을 넓게 펼쳤다가 좁힌 뒤 표 너비와 셀 줄바꿈, 표 아래 문장의 위치를 함께 살펴봅니다.<br><br>두 번째 문단입니다. 빈 줄도 셀 안의 높이에 포함되어야 합니다. |
| 텍스트 선택 | 긴 문장의 앞부분부터 여러 줄에 걸쳐 선택한 다음 복사한 내용이 원문과 같은지 확인합니다. 자동 줄바꿈이 생긴 위치에는 저장용 개행 문자가 추가되지 않아야 합니다. 밝은 화면과 어두운 화면에서 머리글, 선택한 셀, 테두리와 본문의 구분이 잘 보이는지 확인합니다. |
| 실행 취소 | 같은 셀에 이어서 입력한 내용을 되돌린 뒤 다시 실행하여 원래 문장과 선택 위치가 복원되는지 확인합니다. 다른 셀로 이동한 후 입력한 내용과 행 추가는 각각 구분하여 되돌립니다. 여러 줄 셀과 특수 문자가 들어 있는 문서를 저장한 뒤 다시 열어 같은 내용으로 표시되는지 확인합니다.<br><br>두 번째 문단입니다. 빈 줄도 셀 안의 높이에 포함되어야 합니다. |
| 창 크기 변경 | 창을 넓게 펼쳤다가 좁힌 뒤 표 너비와 셀 줄바꿈, 표 아래 문장의 위치를 함께 살펴봅니다. 표가 사용할 수 있는 너비가 500픽셀보다 좁아지면 표 전체를 가로로 이동해 확인합니다. 여러 문서를 번갈아 선택하면서 표의 현재 위치와 편집하던 셀의 상태를 확인합니다. |
| 화면 테마 | 밝은 화면과 어두운 화면에서 머리글, 선택한 셀, 테두리와 본문의 구분이 잘 보이는지 확인합니다. 색상 변경은 문서의 저장 문자열과 실행 취소 기록에 영향을 주지 않습니다. 마우스를 사용하지 않고 셀 사이를 이동하고, 표의 처음과 끝에서 본문으로 나가는 동작을 확인합니다.<br><br>두 번째 문단입니다. 빈 줄도 셀 안의 높이에 포함되어야 합니다. |

위 표의 짧은 항목 셀도 오른쪽의 긴 내용 셀과 같은 높이를 사용합니다.
