# 마크다운 표 편집 예제

이 문서는 렌더 모드에서 표와 일반 문장을 함께 편집하는 예제입니다.

| 품목 | 수량 | 가격 |
| :--- | :---: | ---: |
| 연필 | 2 | 1,000원 |
| 공책 | 3 | 2,000원 |
| 지우개 | 1 | 500원 |

셀을 클릭해 내용을 고치거나, 행·열 손잡이로 순서를 바꿔 보세요.
실행 취소와 다시 실행은 표 편집에도 적용됩니다.

| 이름 | 설명 |
| --- | --- |
| 파이프 | A\|B |
| 여러 줄 | 첫 번째 줄<br>두 번째 줄 |
| 빈 셀 | |

원문 모드로 전환하면 표의 마크다운 문자열을 확인할 수 있습니다.

## 코드 예제는 원문 그대로

```markdown
| 머리글 | 값 |
| --- | --- |
| 예제 | 코드 안에서는 표로 변환하지 않습니다. |
```
