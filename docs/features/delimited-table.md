# CSV/TSV 표 편집 계약

CSV는 쉼표로 셀을 구분하는 표 데이터 형식이고, TSV는 탭으로 셀을 구분하는 표 데이터 형식이다. 두 형식은 원문 모드에서는 저장 문자열을 그대로 편집하고, 렌더 모드에서는 컴팩트한 표 편집기로 표시한다.

## 표시 기준

- `.csv`는 쉼표, `.tsv`는 탭을 열 구분자로 사용한다.
- 표 위의 한 줄 도구 모음에는 형식, 행 수, 열 수와 표시 설정만 배치한다. 행·열 구조 편집 버튼은 도구 모음에 두지 않는다.
- 데이터의 첫 번째 행을 표 머리글로 사용하고 본문에는 중복 표시하지 않는다. 머리글 셀도 직접 편집할 수 있으며 저장 데이터의 첫 번째 행을 바꾼다.
- 헤더 강조 설정은 첫 번째 행의 배경과 글자 강조만 바꾸며 원문을 바꾸지 않는다.
- 왼쪽 행 번호는 표시하거나 숨길 수 있다. 행 번호를 숨겨도 행 이동용 손잡이는 유지한다.
- A, B, C 같은 별도 조작용 머리글은 표시하지 않는다. 열 이동 손잡이와 너비 조절선은 첫 데이터 행을 사용하는 머리글 셀 안에 둔다.
- 표의 위쪽과 왼쪽에는 조작 버튼 한 개가 들어가는 전용 여백을 둔다. 이 여백의 버튼은 셀 내용과 경계선을 덮지 않는다.
- 셀은 여러 줄 값을 표시할 수 있지만 기본 높이는 한 줄로 유지하고 최대 네 줄 높이 안에서 스크롤한다.
- 표 영역은 가로와 세로로 독립 스크롤한다.

## 편집 기준

- 셀을 직접 입력하면 즉시 원문 CSV/TSV 문자열에 반영한다.
- `Tab`과 `Shift+Tab`은 다음 셀과 이전 셀로 초점을 옮긴다.
- 왼쪽 전용 여백에서 행과 행 사이에 포인터를 두거나 키보드 초점을 옮기면 `+` 버튼을 표시하고, 해당 위치에 빈 행을 추가한다.
- 위쪽 전용 여백에서 열과 열 사이에 포인터를 두거나 키보드 초점을 옮기면 `+` 버튼을 표시하고, 해당 위치에 빈 열을 추가한다.
- 왼쪽 전용 여백의 각 행 중앙과 위쪽 전용 여백의 각 열 중앙에는 가까이 접근하거나 키보드 초점을 옮겼을 때 `-` 버튼을 표시한다. 열 제거 감지 너비는 해당 셀 너비의 절반, 행 제거 감지 높이는 해당 셀 높이의 절반으로 하되 각각 버튼 크기보다 작아지지 않게 한다. 마지막 한 행이나 한 열을 제거하면 표 구조는 남기고 해당 셀 값을 비운다.
- 숨겨진 `+`, `-` 버튼의 포인터 감지 영역은 전용 여백 안에만 두어 데이터 셀과 경계선 조작을 가로막지 않는다.
- 마우스로 조작 버튼을 누른 뒤 포인터가 감지 영역을 벗어나면 버튼을 다시 숨긴다. 조작 버튼과 감지 영역에서는 잡기형 커서를 상속하지 않고 일반 포인터를 유지한다.
- 행과 열의 순서 이동은 `::` 모양 손잡이에서만 시작한다. 브라우저 기본 드래그 방식은 사용하지 않고 눌린 포인터의 위치를 표 내부에서 추적한다. 포인터가 셀의 앞쪽 절반에 있으면 해당 행·열의 앞 경계, 뒤쪽 절반에 있으면 뒤 경계를 삽입 위치로 사용한다. 첫 행을 이동하면 이동 뒤 첫 번째 행이 새 머리글이 된다.
- 드래그 중에는 원본 표를 계속 재배치하지 않고 행 또는 열의 미리보기가 포인터를 따라간다. 드롭 위치는 셀 박스가 아니라 행 사이의 가로선 또는 열 사이의 세로선으로 표시한다. 미리보기는 드래그 시작 시 한 번 만들고, 긴 열은 현재 화면에 보이는 셀만 복제한다. 포인터 이동 중에는 브라우저 화면 갱신 주기마다 위치 속성만 바꾸고 경계가 달라질 때는 삽입선 하나의 위치만 갱신하며, 실제 데이터 순서는 놓는 순간 한 번만 변경한다.
- 이동 애니메이션이 켜져 있으면 드롭하는 순간 이동 경로의 주변 행·열이 실제 표 안에서 밀려나고, 포인터를 따르던 대상 미리보기가 열린 공간으로 들어간다. WebView의 표준 Web Animations API로 대상 미리보기와 현재 화면에 보이는 실제 행·열 요소의 `transform`을 같은 시간의 `ease-out` 곡선으로 전환하며, 전환 완료가 보고된 뒤에만 원본 배열 순서를 동기 반영한다. 긴 표에서도 화면 밖 요소를 복제하거나 갱신하지 않아 전체 표의 레이아웃 계산을 반복하지 않는다. 이동 시간은 설정의 `렌더 모드 > 표`에서 0.05초부터 2초까지 0.05초 단위로 조절하며 기본값은 0.15초다. 이 앱의 설정에서 기능을 끈 경우에만 위치 전환을 생략하고 즉시 순서를 바꾼다.
- 메인 메뉴의 드롭다운이 열린 동안에는 파일·편집 메뉴가 표와 드래그 미리보기보다 높은 쌓임 맥락을 유지한다. 드롭다운과 겹치는 행·열 추가·제거 감지 영역은 화면에 그려지거나 포인터 입력을 받지 않는다.
- 행이나 열을 이동한 뒤에는 새 위치의 `::` 손잡이에 키보드 포커스를 두고 표의 현재 스크롤 위치를 유지한다.
- 열 경계선은 가로 방향으로 드래그해 너비를 조절하고, 두 번 클릭하면 해당 열의 가장 긴 내용에 맞춘 너비로 바꾼다. 키보드에서는 `왼쪽/오른쪽`으로 8픽셀, `Shift+왼쪽/오른쪽`으로 32픽셀씩 조절하고 `Enter`로 내용에 맞춘다.
- 키보드에서는 행 손잡이에서 `Alt+위/아래`, 열 손잡이에서 `Alt+왼쪽/오른쪽`으로 이동한다.
- 파일 형식별 렌더 편집 설정이 꺼져 있으면 셀 입력과 행·열 구조 변경을 막는다. 헤더 강조와 행 번호 표시는 원문을 바꾸지 않으므로 계속 조작할 수 있다.

## 원문 보존과 직렬화

- 파서는 큰따옴표로 감싼 셀, 셀 안의 구분자, `""`로 이스케이프된 큰따옴표, 셀 안의 줄바꿈을 인식한다.
- 표 편집 뒤에는 형식에 맞는 구분자로 원문을 다시 만든다.
- 구분자, 큰따옴표, 줄바꿈이 들어 있는 셀만 큰따옴표로 감싸고 내부 큰따옴표는 두 번 써서 이스케이프한다.
- 문서에서 처음 확인한 줄바꿈 방식과 마지막 줄바꿈 유무를 유지한다.
- 행·열 구조 편집은 원문 전체의 배열 순서를 바꾸므로 필요한 인용 표기는 정규화할 수 있다. 값 자체는 바꾸지 않는다.

## 실행 취소

- 셀에서 짧게 이어지는 입력은 같은 셀 안에서 하나의 일반 입력 묶음으로 기록한다.
- 행·열 추가, 제거, 드래그 이동은 각각 한 번의 실행 취소 단위로 기록한다.
- 헤더 강조, 행 번호 표시, 이동 애니메이션과 열 너비는 원문 변경이 아니므로 실행 취소 기록에 넣지 않는다.

## 남은 안전 기준

- 스프레드시트 프로그램이 `=`, `+`, `-`, `@`로 시작하는 셀을 수식으로 실행할 수 있으므로 CSV 수식 주입 위험 감지는 별도 작업으로 남긴다.

## 샘플 파일

- `samples/sample-orders.csv`: 큰따옴표, 쉼표, 셀 내부 줄바꿈을 포함한 일반 주문 데이터 예제다.
- `samples/large-orders.csv`: 2,500개 데이터 행으로 긴 문서의 스크롤과 구조 편집을 확인하는 예제다.
