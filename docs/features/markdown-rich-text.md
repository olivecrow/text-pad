# Markdown 서식과 HTML 표시

Markdown 문서는 기존 줄 편집·표 편집과 복합 서식 미리보기를 함께 사용한다. 저장·복사·실행 취소의 기준은 원문이며, 표시 결과를 다시 Markdown으로 직렬화하지 않는다.

## 표시 범위

- 일반 줄의 `**굵게**`, `__굵게__`, `*기울임*`, `_기울임_`, `***굵은 기울임***`, `~~취소선~~`은 서식 표식을 숨겨 표시하고 원문 위치로 직접 편집한다. `**굵게 *중첩 기울임* 끝**`, `*기울임 **중첩 굵게** 끝*`, 따옴표 안의 강조도 해석한다. 쌍이 맞지 않는 표식, 표식 안쪽에 공백이 붙은 `* 문구 *`, 단어 중간의 밑줄과 이스케이프한 표식은 강조하지 않는다. 코드 안의 별표도 원문으로 유지한다.
- `>`로 시작하는 연속 인용문은 왼쪽 세로선과 들여쓰기가 있는 한 영역으로 묶는다. `>`만 있는 빈 줄은 같은 영역의 문단을 나누고, `> >`는 중첩 인용문이다. 인용문 안의 강조·목록·링크·표·코드와 표식 없이 이어지는 문장은 공용 Markdown 해석기의 문단 경계를 따른다. 빈 줄 뒤의 일반 문단은 인용문 밖에 둔다.
- 여러 원문 줄에 걸친 강조는 해당 문단을 복합 서식으로 표시한다. 인용문과 여러 줄 강조의 편집은 복합 영역의 원문 전환 경로를 사용한다.
- HTML 블록과 HTML·이미지·링크·문자 참조가 들어 있는 문단, 가로 구분선은 복합 서식 미리보기로 표시한다. `&amp;`, `&nbsp;`, 숫자 문자 참조도 해석한다.
- 글자 서식: `strong/b`, `em/i`, `del/s`, `ins/u`, `sub/sup`, `small`, `mark`, `code`, `kbd`, `samp`, `var`, `abbr`, `cite`, `q`, `dfn`, `ruby/rt/rp`, `bdi/bdo`, `time`.
- 문서 구조: `p`, `div`, `span`, `center`, `h1`~`h6`, `br/wbr`, `hr`, `blockquote`, `ul/ol/li`, `dl/dt/dd`, `figure/figcaption`, `table/caption/colgroup/col/thead/tbody/tfoot/tr/th/td`.
- 접기 영역: 중첩 `details/summary`, 초기 `open` 속성. 영역 안에서 빈 줄로 분리된 Markdown 문단·목록·표·코드도 해석한다. HTML 안의 Markdown 해석은 CommonMark의 HTML 블록 경계를 따른다.
- 링크·이미지: `a`, `img`, Markdown 링크·이미지와 문서 다른 곳의 정의를 사용하는 참조형 링크·이미지. 정렬 `align`, 이미지 `width/height`, 표 `colspan/rowspan`, 목록 `start/reversed/value`, `title/alt`, 글 방향 `dir`과 언어 `lang`을 제한된 속성으로 지원한다.
- 복합 본문의 링크 문구는 클릭해 편집하고 Ctrl+클릭(또는 Command+클릭)으로 연다. 외부 링크는 운영체제의 기본 브라우저로 열고 `#제목` 링크는 문서 제목 위치로 이동한다. 표 셀 미리보기의 링크는 기존 일반 클릭을 유지한다. 외부 문서 경로·실행 파일·사용자 정의 프로토콜을 임의 실행하지 않는다.

## 표 셀의 서식과 편집

- Markdown 본문 표의 머리글·본문 셀에도 중첩 굵게·기울임·취소선, 인라인 코드, 허용된 HTML 태그, 문자 참조, 링크·이미지를 표시한다. 문서 전체의 참조형 링크 정의를 공유하고 상대 이미지는 문서 경로를 기준으로 읽는다. 셀에서는 인라인 Markdown 규칙을 사용하며 표 안에 별도의 제목·목록 블록을 만들지 않는다.
- 포커스가 없는 셀은 서식 미리보기다. 셀 본문을 클릭하면 그 셀의 Markdown 입력값 전체를 선택해 편집하고, 키보드로 진입하면 기존 셀의 선택 위치를 사용한다. 포커스를 잃으면 미리보기로 돌아간다. 서식 글자 폭으로 숨긴 태그의 편집 위치를 추측하지 않는다. 링크와 접기 제목은 해당 동작을 유지한다.
- 셀의 입력값은 태그·문자 참조·백슬래시 이스케이프를 포함한 Markdown이다. `&lt;kbd&gt;`는 문자로 표시되며 `<kbd>` 태그와 구분한다. 셀 구분용 이스케이프 파이프, 코드 밖의 `<br>`와 양끝 공백 참조만 편집용 문자로 변환하고 각 경계를 원문에 연결한다. 입력한 `<br>`도 줄바꿈이 되며, 코드 안의 `<br>`는 문자로 유지한다.
- 셀 수정과 행·열 이동 때 HTML·문자 참조를 다시 일반 문자로 이스케이프하지 않는다. 입력과 미리보기 전환 자체는 원문·실행 취소를 바꾸지 않는다. 미리보기의 실제 높이와 편집 중 입력값의 높이를 각각 행 배치에 반영한다.
- CSV/TSV 셀은 기존 일반 텍스트 편집을 유지한다. 보안 허용 목록과 주소 제한은 표 밖의 복합 서식과 동일하다.

## 이미지

- HTTP/HTTPS 이미지는 브라우저 이미지 요소로 표시하고 참조 페이지 주소를 보내지 않는다. 외부 이미지 서버에는 이미지 요청이 전달된다.
- 저장된 문서의 상대 이미지 경로는 `read_document_image` 명령으로 읽는다. 사용자가 연 문서의 승인 경로를 먼저 확인하고, 실제 경로가 그 문서 폴더 안에 있는 이미지만 허용한다. 상위 폴더 밖 이동, 절대 경로, 임의 파일 형식은 거절한다.
- PNG, JPEG, GIF, WebP, SVG, AVIF, BMP, ICO를 지원하며 로컬 이미지 하나는 최대 4 MiB다. SVG도 실행 가능한 문서로 삽입하지 않고 이미지 요소로만 표시한다. 사용을 마친 임시 이미지 주소는 해제한다.
- 문서가 아직 저장되지 않았거나 이미지 파일이 없으면 원문과 대체 텍스트를 유지한다. `samples/ouroboros README.ko.md`에 적힌 `./docs/images/ouroboros.png` 파일 자체는 이 저장소에 포함되어 있지 않다.

## 편집과 배치

- HTML·인용문·여러 줄 강조·링크 문단은 렌더 모드를 유지한 채 클릭한 글자 위치에서 편집한다. 해석기가 소비한 원문 범위를 표시 글자의 경계에 연결하며, 같은 문구가 속성·주소·본문에 반복돼도 전체 문자열 재검색으로 위치를 추측하지 않는다. 문자 참조, 코드, CRLF와 제거된 인용 접두부를 원문 위치에 반영한다.
- 클릭·Shift+클릭·드래그·두 번 클릭 선택, 캐럿, 방향키·Home/End는 같은 표시 경계를 사용한다. 한글 조합 입력은 기존 입력 요소와 실행 취소 경로를 사용한다. Backspace/Delete는 표시 문자 또는 문자 참조의 전체 원문 범위를 지우며 숨은 태그를 한 글자씩 훼손하지 않는다. HTML 본문의 Enter는 `<br>`, Markdown 본문은 강제 줄바꿈과 현재 인용 접두부를 넣는다. 코드 안에서는 원문 줄바꿈을 사용한다.
- `‹/›` 버튼은 태그·주소 등 문법 자체를 편집할 때 원문 모드로 전환하고 해당 영역을 선택한다. 해석기의 원문 경계를 확인할 수 없는 블록은 그 블록만 편집 가능한 원문으로 표시한다.
- 접기 제목은 클릭해 편집하고 Ctrl+클릭(또는 Command+클릭)으로 펼치거나 접는다. 열린 상태는 내용 입력 중에도 유지한다.
- 접기·펼치기와 모드 전환은 원문이나 실행 취소 기록을 바꾸지 않는다. 원문 변경은 기존 입력·실행 취소 경로로 처리한다.
- 실제 미리보기 높이를 기존 줄 배치에 반영한다. 이미지 로드, 접기·펼치기, 창 폭 변경 뒤에도 다음 문단과 겹치지 않는다. 화면 밖에서는 기존 가상화 방식을 사용한다.
- 복합 HTML·인용문 안의 표는 미리보기의 일부다. 그 밖의 Markdown 표는 기존 공통 셀 편집기를 그대로 사용한다.
- 코드 블록과 인라인 코드 안의 태그를 HTML로 실행하지 않는다. 문서 전체 렌더 예산 외에 복합 블록은 500개, 블록당 원문은 128 KiB, Markdown 중첩 해석은 32단계로 제한한다. 범위를 넘는 블록은 기존 원문 표시로 남긴다.

## 보안과 구현

- [markdown-it](https://github.com/markdown-it/markdown-it)으로 Markdown을 해석하고 [DOMPurify](https://github.com/cure53/DOMPurify) 허용 목록으로 최종 HTML을 정리한다.
- 스크립트, 이벤트 속성, 임의 스타일·클래스·식별자, 폼, iframe, 직접 삽입한 SVG/MathML, 위험한 주소 프로토콜을 제거한다. 사용자 문서가 앱의 선택·입력용 속성을 위조할 수 없다.
- `src/lib/markdown-rich-text.ts`: 원문 범위 탐색, Markdown 해석, HTML 정리, 내부 제목 링크.
- `src/lib/markdown-source-renderer.ts`, `src/lib/markdown-rich-geometry.ts`: 해석기 소비 범위와 안전한 표시 글자의 원문 경계, 캐럿·선택·좌표 변환. 호출마다 생성하는 속성을 통해서만 정리 단계에 위치 정보를 전달하고 사용자 원문의 편집 속성은 제거한다.
- `src/lib/markdown-inline.ts`: 공용 해석기의 강조 쌍 판정을 원문 길이를 보존한 줄 토큰에 연결한다. 정규식으로 중첩 강조를 다시 해석하지 않는다.
- `src/lib/MarkdownRichBlock.svelte`: 복합 서식 표시, 상대 이미지 수명 관리, 원문 전환 버튼.
- `src/routes/+page.svelte`: 기존 표·줄 배치와 미리보기 연결, 정확한 원문 편집 경계.
- `src-tauri/src/file_commands.rs`: 승인된 문서 기준의 크기·경로 제한 이미지 읽기.
