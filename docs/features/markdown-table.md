# Markdown 표 표시와 편집

Markdown은 기호로 문서 구조를 표현하는 텍스트 형식이다. `.md`, `.markdown`과 저장 전 Markdown 문서의 렌더 모드는 머리글 다음에 `| --- | --- |` 같은 구분 행이 오는 표를 실제 표 편집기로 표시한다.

```markdown
표 앞 문장

| 품목 | 수량 | 가격 |
| :--- | :---: | ---: |
| 연필 | 2 | 1,000원 |
| 공책 | 3 | 2,000원 |

표 뒤 문장
```

## 인식과 표시

- 머리글과 구분 행의 열 수가 같아야 한다. 구분 셀은 하나 이상의 `-`와 선택적인 양끝 `:`로 구성한다. `:---`, `:---:`, `---:`는 각각 왼쪽, 중앙, 오른쪽 정렬이다.
- 양끝 `|`는 생략할 수 있다. 각 표 줄에는 셀을 구분하는 이스케이프되지 않은 `|`가 있어야 한다. `\|`는 셀 안의 문자로 읽으며 열을 나누지 않는다.
- 구분 행은 데이터 행으로 표시하지 않는다. 첫 데이터 행은 편집 가능한 머리글이다. 본문 행이 없는 표와 빈 셀도 허용하며, 짧은 본문 행은 비어 있는 셀로 채워 표시한다.
- 본문은 파이프 행이 연속된 범위까지다. 빈 줄, 파이프가 없는 일반 문장, 다른 블록의 시작에서 끝난다. 머리글보다 셀이 많은 행은 데이터를 숨기거나 버리지 않고 해당 표 전체를 원문으로 표시한다.
- 독립된 본문 표를 지원한다. 코드 울타리 안, HTML 주석 안, 네 칸 이상 들여쓴 코드, 인용과 목록 안의 표는 표 편집기로 변환하지 않는다.
- 한 문서 안의 여러 표를 인식하되 대화형 셀 합계는 2,000개를 넘기지 않는다. 남은 예산보다 큰 표 전체를 원문 표시로 유지하며, 다른 짧은 표의 인식은 계속한다. 전체 고급 렌더 예산도 기존 기준을 따른다.
- 표는 별도 형식 이름·크기 요약·도구 막대·바깥 테두리 없이 본문에 바로 표시한다. 행·열 조작 버튼을 위한 여백만 확보하며, 첫 행 강조와 행 번호는 설정창의 공통 표 설정을 따른다.
- 표는 조작 여백을 제외한 본문의 가용 너비를 채우고 최소 너비 500픽셀을 유지한다. 가용 너비가 500픽셀보다 작을 때 표 영역에 가로 스크롤이 생긴다.
- 열 너비는 머리글을 포함한 전체 셀의 글자 수를 열별로 합산한 뒤 제곱근 비율로 배분한다. 개행은 글자 수에 넣지 않는다. 글자 수가 1:16이면 너비 비율은 1:4로 보정해 짧은 열이 지나치게 좁아지는 것을 완화한다. 각 데이터 열은 최소 100픽셀을 유지하고, 최소 너비에 도달한 열을 제외한 공간을 나머지 열의 보정된 비율로 다시 나눈다. 모든 셀이 비어 있으면 균등하게 배분한다. 열이 많으면 행 조작 열과 각 열의 최소 너비를 담을 만큼 표를 넓히고 가로 스크롤을 사용한다.
- 자동 배분은 내용 편집과 행·열 구조 변경을 반영한다. 사용자가 경계선이나 내용 맞춤 기능으로 너비를 직접 조절한 뒤에는 제곱근 보정 없이 그 비율을 내용 편집과 창 크기 변경에도 유지하되 최소 100픽셀을 적용한다. 수동 너비는 표 편집기의 표시 상태이며 원문에 저장하지 않는다.
- 모든 셀은 내부 스크롤 없이 너비에 맞춰 줄바꿈하고, 행 높이와 그 행의 입력칸 높이는 가장 높은 셀에 맞춘다. 긴 단어도 셀 안에서 나누며, 입력·삭제·창 크기·열 너비 변경에 따라 높이를 다시 맞춘다. 화면 줄바꿈은 원문 개행을 추가하지 않는다.
- 표 위·아래 본문은 기존 렌더 편집을 유지한다. 표 첫 원문 줄에 표 블록의 실측 높이를 반영하고, 같은 표에 흡수된 원문 줄 높이는 0으로 둔다. 줄 번호와 스크롤도 같은 배치를 사용한다. 긴 표는 전체 높이로 펼쳐져 문서와 함께 세로로 스크롤한다.

## 공통 편집기

- CSV/TSV와 `TableEditor.svelte` 및 `table-document.ts`를 공유한다. 셀 입력, 행·열 추가·제거·이동, 열 너비 조절, 첫 행 강조와 행 번호 설정을 중복 구현하지 않는다. 기존 표 테마 색상과 이동 애니메이션 설정도 함께 사용한다.
- `table-column-layout.ts`는 저장 형식과 화면 요소에 의존하지 않고 열별 글자 수 합계의 제곱근 보정과 최소 너비를 반영한 너비 배분을 계산한다. 공통 표 편집기는 자동 배분에만 글자 수 보정을 적용하고, 자동 배분과 수동 조절 모두에 같은 최소 너비 배분 계산을 사용한다.
- 열 이동은 열 정렬도 함께 이동시킨다. 새 열은 기본 정렬을 사용한다. 행 이동 뒤 첫 행이 머리글이 되는 기존 표 편집 규칙을 유지한다.
- 셀은 CSV/TSV와 같은 텍스트 입력 요소다. 강조·링크·인라인 코드의 Markdown 표기는 편집 가능한 텍스트로 유지하고 HTML을 실행하지 않는다. `<br>` 계열 표기는 셀 안의 줄바꿈으로 표시한다.
- `Tab`/`Shift+Tab`으로 셀 사이를 이동한다. 마지막/첫 셀에서 표 밖으로 나가며, `Escape`는 표 뒤로 이동한다. 첫 행 시작의 위 방향키와 마지막 행 끝의 아래 방향키도 표 밖으로 이동한다. `Ctrl+Home`/`Ctrl+End`는 표 앞/뒤로 이동한다.
- 문서 경계에서 표 밖으로 이동할 문단이 없으면 원문의 줄바꿈 방식으로 빈 줄 하나를 만들며, 한 번의 실행 취소로 되돌릴 수 있다. 조합 입력 중에는 셀 이동 단축키를 가로채지 않는다.
- 본문에서 키보드로 표 위치에 진입하거나 실행 취소·다시 실행으로 셀 위치를 복원하면 원문 위치에 해당하는 셀을 선택한다. 원문 전체 선택·복사는 표의 실제 Markdown 문자열을 포함한다.
- Markdown 렌더 표시를 끄면 원문 줄 표시를 사용하고, 렌더 편집을 끄면 표의 셀 입력·구조 조작을 막는다. 원문 모드는 기존 기본 텍스트 편집을 유지한다.

## 원문과 실행 취소

- 표를 표시하거나 모드를 전환하는 것만으로 원문을 바꾸지 않는다.
- 기존 셀 편집은 그 셀의 내용 범위만 교체하고 다른 셀·머리글 구분 행·주변 공백·표 앞뒤 본문을 그대로 보존한다.
- 셀 안의 `|`와 역슬래시를 이스케이프하고 줄바꿈은 `<br>`로 저장한다. 새로 입력한 셀 양끝 공백·탭은 문자 참조로 저장하여 파싱 시 제거되거나 연속 입력마다 늘어나지 않게 한다. 문자 참조는 같은 문자로 다시 표시하고 원문 경계에 연결한다.
- 행·열 조작이나 생략된 셀의 편집은 해당 표 범위만 `| 값 |` 형태로 직렬화한다. 구분 행은 정렬을 유지한 `---` 형태로 만든다. 표의 줄바꿈 방식, 표 밖 원문과 문서 마지막 줄바꿈 유무는 유지한다.
- 모든 변경은 메인 편집기의 자체 실행 취소 경로를 통과한다. 같은 표·같은 셀의 연속 입력만 묶으며, 행·열 조작은 각각 하나의 실행 취소 단위다. 다른 표의 입력을 같은 묶음으로 합치지 않는다.
- 셀 선택 경계를 이스케이프·줄바꿈·문자 참조를 포함한 원문 위치로 변환한다. 실행 취소·다시 실행은 원문과 해당 선택 위치를 함께 복원한다. 오래된 표 원문과 현재 범위가 다르면 변경 콜백을 적용하지 않는다.

## 검증

- `samples/sample-markdown-tables.md`: 본문 사이의 여러 표, 열 정렬, 파이프·줄바꿈 셀과 코드 예제.
- `samples/large-markdown-tables.md`: 120행·6열 작업 목록, 긴 문장과 여러 줄·빈 셀·긴 식별자를 포함한 표 3개. 머리글을 포함한 771개 셀로 너비·줄바꿈·행 높이와 긴 문서 스크롤을 확인한다.
- `npm run test:rendering`: LF/CRLF, 표 범위, 정렬, 이스케이프, 셀 양끝 공백, 줄바꿈, 주변 원문 보존, 코드·주석 제외와 셀 예산.
- `tests/browser/markdown-tables.spec.js`: 실제 셀 입력·키 이동, 실행 취소·다시 실행, 구조 조작, 창 너비 변경, 표 높이와 문서 끝 스크롤, 설정별 동작과 CSV/TSV 공통 화면 회귀.
- `tests/browser/table-layout.spec.js`: Markdown/CSV/TSV의 가용 너비 채우기와 최소 500픽셀, 머리글·긴 단어·여러 줄 셀의 내부 넘침 방지, 행 높이 일치, 내용 삭제·실행 취소와 열 너비 조절.
- 같은 검사에서 내용 합계의 제곱근 비율, 빈 열과 최소 100픽셀, 열 이동·내용 변경 후 재배분, 직접 조절한 비율 유지와 열이 많은 표의 가로 스크롤도 확인한다.
