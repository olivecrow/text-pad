# 렌더 모드 계약

렌더 모드는 원문을 다시 작성하지 않고, 같은 텍스트를 읽기 쉽게 겹쳐 보여주는 표시 기능이다.

## 표시 구조

- 실제 입력과 선택 영역은 여러 줄 텍스트 입력 요소인 HTML `textarea`가 담당한다.
- 구문 강조, 줄 번호, 들여쓰기 가이드는 `textarea` 뒤의 배경 레이어가 담당한다.
- 두 레이어의 글꼴, 글자 크기, 줄 높이, 탭 크기, 스크롤 위치가 어긋나면 선택 영역과 글자가 맞지 않으므로 항상 함께 갱신한다.

## 현재 강조 범위

- 백틱 코드 조각.
- 닫힘이 있는 작은따옴표와 큰따옴표 문자열.
- 단어에 붙어 줄임, 소유, 발음 표기 등에 쓰이는 작은따옴표 모양 기호는 문자열로 보지 않는다.
- 숫자.
- `#000000` 형태의 6자리 색상 코드.
- 파일 형식별 주석.
- 소괄호, 대괄호, 중괄호와 그 내부 중첩 구조.
- 괄호와 따옴표 같은 중첩 요소는 요소 종류보다 중첩 깊이를 우선해서 색상을 정한다.
- 들여쓰기 단계별 가이드 라인.

## 파일 형식별 주석

주석은 파일 이름의 마지막 점 뒤 문자열인 확장자에 맞는 문법만 인식한다. 확장자가 없거나 아래 목록에 없으면 주석 강조를 하지 않는다.

- `.bash`, `.py`, `.r`, `.rb`, `.sh`, `.toml`, `.yaml`, `.yml`, `.zsh`: `#`.
- `.c`, `.cpp`, `.cs`, `.go`, `.h`, `.java`, `.js`, `.jsx`, `.kt`, `.rs`, `.swift`, `.ts`, `.tsx`: `//`, `/* ... */`.
- `.php`: `//`, `#`, `/* ... */`.
- `.css`: `/* ... */`.
- `.html`, `.md`, `.svg`, `.xml`: `<!-- ... -->`.
- `.ini`, `.cfg`: 줄 첫 공백 뒤의 `;` 또는 `#`.
- `.bat`, `.cmd`: 줄 첫 공백 뒤의 `REM` 또는 `::`.
- `.ps1`: `#`, `<# ... #>`.
- `.sql`: `--`, `/* ... */`.
- `.lua`: `--`, `--[[ ... ]]`.
- `.vim`: `"`.
- `.jsonc`: `//`, `/* ... */`.

일반 소설, 로그, 표 데이터처럼 `.txt`, `.log`, `.json`, `.csv`, `.tsv` 파일은 주석 강조 대상이 아니다.

## 파싱 기준

- 줄 단위 토큰화를 사용한다.
- 괄호와 따옴표처럼 안쪽 구조가 필요한 요소는 트리 형태 토큰으로 만든다.
- `#000000` 형태의 색상 코드는 `#` 주석보다 먼저 판정한다.
- 주석 안에 들어 있는 `#000000` 형태의 색상 코드도 주석보다 안쪽 요소로 다시 강조한다.
- 색상 코드의 배경과 테두리는 실제 글자 폭을 바꾸지 않는 방식으로 표시해 원문 입력 커서 위치와 렌더 표시 위치를 맞춘다.
- 색상 코드 안에 입력 커서가 있을 때는 색상 코드 배경과 대비되는 입력 커서 색을 사용한다.
- 색상 코드에 마우스를 올리면 입력 영역 커서를 조작 가능 상태로 바꾼다.
- 색상 코드를 클릭하면 별도 정사각형 색상 필드를 만들지 않고, 숨겨진 앵커를 통해 운영체제 색상 선택기만 연다.
- 색상 선택기의 숨겨진 앵커는 색상 코드의 오른쪽 끝을 기준으로 배치하고, 화면 여백에 따라 위치를 보정한다.
- 색상 선택기의 숨겨진 앵커는 화면에 보이는 픽셀을 남기지 않아야 하며, 색상 코드가 없어지거나 선택기 적용이 끝나면 편집 영역 밖으로 치운다.
- 렌더 모드에서 캐럿만 놓인 상태로 여는 괄호나 따옴표를 입력하면 닫는 짝 문자를 함께 넣고 캐럿을 가운데로 둔다. 단, 캐럿 오른쪽에 이미 닫는 짝 문자가 있으면 자동 삽입을 하지 않고 일반 입력에 맡긴다.
- 렌더 모드에서 자동 쌍 문자 사이에 캐럿만 있고 안쪽 내용이 비어 있을 때 앞 글자를 지우면 닫는 짝 문자도 함께 지운다.
- 여러 줄 주석은 닫힘이 나올 때까지 다음 줄 상태를 이어 간다.
- 괄호와 따옴표는 같은 줄 안에서 닫힘이 확인된 경우에만 강조하고, 닫힘이 없으면 일반 텍스트로 둔다.
- 닫힘이 확인된 중첩 요소는 최종 토큰 트리의 바깥쪽에서 안쪽 순서대로 깊이를 다시 계산한다.
- 깊이 색상은 기존 렌더 색상 설정을 재사용하며, 깊이가 색상 우선순위가 된다.
- Svelte 템플릿 공백이 실제 글자 폭에 영향을 주지 않도록 토큰 재귀 렌더링 부분은 불필요한 줄바꿈과 공백을 넣지 않는다.
- 강조 색상은 CSS 변수로 주입하고 저장 원문에는 영향을 주지 않는다.

## 성능 기준

- 화면에 보이는 줄 주변만 렌더링하는 가상화 표시를 유지한다.
- 큰 파일에서도 전체 줄을 DOM 요소로 한꺼번에 만들지 않는다.
- 수직 스크롤과 수평 스크롤은 원문 `textarea` 기준으로 동기화한다.

## Windows 가로 휠

Windows WebView2가 일부 가로 휠 입력을 브라우저 이벤트로 제대로 넘기지 않기 때문에, 백엔드가 `WM_MOUSEHWHEEL` 메시지를 받아 `native-horizontal-wheel` 이벤트로 전달한다. 프론트엔드는 이 값을 받아 `textarea`의 가로 스크롤 위치에 반영한다.
