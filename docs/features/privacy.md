# 개인정보 처리 및 외부 통신 안내

이 문서는 `text-pad` 앱이 처리하는 로컬 데이터와 외부 요청을 설명한다. 프로젝트 유지보수자는 [olivecrow](https://github.com/olivecrow)이며, 공개 문의는 [GitHub Issues](https://github.com/olivecrow/text-pad/issues)를 이용할 수 있다. 공개 문의에는 개인 문서나 인증 정보를 첨부하지 않는다.

## 로컬 문서와 설정

- 사용자가 선택한 파일을 컴퓨터에서 읽고 편집하며, 저장할 때 선택한 경로에 쓴다.
- 앱 자체에는 문서 원문을 서버로 업로드하는 기능이나 사용 통계·광고·분석 수집 기능이 없다.
- 글꼴, 테마, 편집 옵션 등 사용자 설정은 앱의 로컬 저장 공간에 보관한다.
- 파일은 항상 원문 텍스트로 저장한다. 앱의 로컬 데이터 처리에는 온라인 계정이 필요하지 않다.

## 앱 업데이트 요청

- 앱은 시작 세션마다 한 번 GitHub Releases의 업데이트 정보를 자동 확인한다. 도움말 메뉴에서도 사용자가 확인을 실행할 수 있다.
- 확인 주소는 `https://github.com/olivecrow/text-pad/releases/latest/download/latest.json`이다. GitHub가 다운로드 요청을 다른 배포 주소로 연결할 수 있다.
- 요청을 받는 서비스에는 IP 주소와 일반적인 HTTP 요청 정보가 전달된다. 앱은 이 업데이트 확인에 편집 중인 문서 원문이나 로컬 파일 경로를 첨부하지 않는다.
- 새 설치 파일의 다운로드와 설치는 사용자가 업데이트를 선택하고 저장 확인을 마친 뒤 수행한다.
- 현재 앱 설정에는 시작 시 자동 업데이트 확인을 끄는 항목이 없다. 이 상태를 선택 가능한 기능으로 안내하지 않는다.

GitHub의 처리는 [GitHub 개인정보 처리방침](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)을 따른다.

## 문서의 외부 이미지와 링크

- 렌더 모드에서 문서에 포함된 HTTP/HTTPS 이미지를 표시하면 해당 이미지 서버에 요청이 전달된다. 화면 표시와 지연 로딩에 따라 요청 시점이 달라질 수 있다.
- 이미지 서버에는 IP 주소와 요청한 이미지 주소가 전달될 수 있다. 이미지 주소에 포함된 정보도 해당 서버에 전달되므로 민감한 정보를 포함한 주소를 사용하지 않는다.
- 이미지 요청은 참조 페이지 주소를 보내지 않도록 설정한다. 이미지 표시를 위해 문서 전체나 로컬 문서 경로를 별도로 업로드하지 않는다.
- 원문 모드는 렌더용 외부 이미지를 표시하지 않는다. 상대 경로 이미지는 승인된 문서 폴더 안의 로컬 파일에서 읽는다.
- 사용자가 외부 링크를 열면 운영체제의 기본 브라우저와 링크 대상 서비스가 요청을 처리한다. 링크 대상의 개인정보 처리방침은 해당 서비스에서 확인한다.

## 운영체제 구성요소

앱 화면은 Microsoft의 WebView2 런타임을 사용한다. 설치 시 필요한 런타임 다운로드와 운영체제 구성요소의 통신은 Microsoft의 정책과 사용자 시스템 설정을 따른다. 관련 안내는 [Microsoft 개인정보 처리방침](https://privacy.microsoft.com/privacystatement)을 참고한다.

## 안내 유지 기준

외부 통신, 사용자 데이터 수집 또는 전송 대상을 변경할 때는 구현과 함께 이 문서를 갱신한다. SignPath 심사에서 설치 중 개인정보 안내나 통신 중지 옵션을 요구하면 제품에 반영하고 실제 동작을 검증한 뒤 충족 여부를 판단한다.
