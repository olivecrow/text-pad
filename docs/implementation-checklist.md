# text-pad Implementation Checklist

`text-pad`는 텍스트 기반 파일을 원문 그대로 안전하게 보존하면서, 사람이 읽기 좋은 렌더링 모드와 편리한 편집 경험을 제공하는 가벼운 데스크톱 편집기다. 이 문서는 구현 순서를 체크리스트로 관리하기 위한 기준 문서다.

## Product Principles

- [ ] 원본 텍스트를 항상 저장의 기준으로 삼는다.
  - 렌더링 모드는 원본 텍스트를 보기 좋게 해석한 화면이어야 하며, 원본을 임의로 재작성하지 않는다.
  - 저장 시 줄바꿈 방식, 들여쓰기, 공백, 따옴표, 주석, 키 순서, 구분자 같은 사용자의 의도를 최대한 보존한다.
- [ ] 모든 파일 형식은 `원문 모드`와 `렌더링 모드`를 가진다.
  - 원문 모드는 IDE나 코드 편집기처럼 정확한 텍스트 편집을 제공한다.
  - 렌더링 모드는 파일 형식에 맞는 보기 좋은 표현과 편리한 편집 표면을 제공한다.
- [ ] 공통 편집 기능과 파일 형식별 기능을 분리한다.
  - 공통 기능은 파일 열기, 저장, 탭, 검색, 다중 캐럿, 자동 들여쓰기, 괄호/따옴표 페어링 같은 편집기 기반 기능이다.
  - 형식별 기능은 Markdown 미리보기, JSON 트리, CSV 표 편집, YAML 구조 보기처럼 특정 파일 형식에만 의미 있는 기능이다.
- [ ] 앱은 가볍고 빠르게 동작해야 한다.
  - 기본 실행 속도, 큰 파일 열기, 스크롤, 검색, 렌더링 전환이 느려지지 않도록 성능 예산을 둔다.
  - 기능이 늘어나도 초기 실행에 필요하지 않은 기능은 지연 로딩한다.
- [ ] 로컬 파일 편집기의 보안 경계를 명확히 한다.
  - Markdown HTML, 외부 이미지, 링크 미리보기, CSV 수식, YAML 태그처럼 실행이나 외부 요청으로 이어질 수 있는 요소는 기본적으로 제한한다.
  - 파일 시스템 접근은 사용자가 선택한 파일과 명시적으로 허용된 경로로 제한한다.

## Phase 0 - Project Foundation

- [ ] 기술 스택을 확정한다.
  - 권장 기본값: Tauri 2, Rust, TypeScript, Svelte, CodeMirror 6.
  - Electron을 선택할 경우 앱 크기와 메모리 사용량 증가를 감수할 이유를 문서화한다.
- [ ] 저장소 기본 구조를 만든다.
  - [ ] `src-tauri/` 또는 네이티브 백엔드 영역
  - [ ] `src/` 또는 프론트엔드 영역
  - [ ] `docs/` 문서 영역
  - [ ] `samples/` 수동 검증용 샘플 파일 영역
  - [ ] `tests/` 자동 검증 영역
- [ ] 앱의 핵심 용어를 정의한다.
  - [ ] 원문 모드: 실제 파일 텍스트를 그대로 편집하는 모드
  - [ ] 렌더링 모드: 파일 형식에 맞춰 읽기 좋게 표현하고, 가능한 경우 구조적으로 편집하는 모드
  - [ ] 문서 모델: 원본 텍스트, 파일 형식, 파싱 결과, 렌더 상태, 편집 상태를 묶는 내부 상태
  - [ ] 라운드트립: 렌더링 모드에서 편집한 결과가 원본 텍스트로 안전하게 되돌아가는 과정
- [ ] 초기 지원 파일 형식의 우선순위를 정한다.
  - [ ] 1차: `.txt`, `.md`
  - [ ] 2차: `.json`
  - [ ] 3차: `.csv`, `.tsv`
  - [ ] 4차: `.yaml`, `.yml`

## Format Expansion Order

1. `.txt`: 원문-렌더링 전환의 기본 모델을 만든다.
2. `.md`: 보기 좋은 렌더링과 부분 편집의 첫 실제 사례를 만든다.
3. `.json`: 구조화된 트리 렌더링과 값 편집 모델을 만든다.
4. `.csv` / `.tsv`: 표 기반 렌더링과 셀 편집 모델을 만든다.
5. `.yaml` / `.yml`: 주석과 순서 보존이 중요한 구조 텍스트 편집 모델을 만든다.

## Definition of Done

- [ ] 구현된 기능은 원문 모드와 렌더링 모드에서 모두 검증되었다.
- [ ] 렌더링 모드의 편집 결과가 원본 텍스트에 안전하게 반영된다.
- [ ] 저장 후 다시 열어도 사용자가 의도하지 않은 포맷 변경이 없다.
- [ ] 관련 자동 테스트가 있다.
- [ ] 자동 테스트로 확인하기 어려운 UI 동작은 수동 검증 체크리스트에 기록되어 있다.
- [ ] 보안상 위험한 렌더링이나 외부 요청은 기본적으로 차단된다.
- [ ] 색상, 테마, 글꼴, 줄 높이 설정이 렌더링 모드에 반영된다.
- [ ] 문서가 현재 구현 상태와 맞다.
