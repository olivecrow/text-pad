# text-pad 구현 체크리스트

이 문서는 현재 남은 기능과 완료 기준만 관리한다.

## 제품 원칙

- [ ] 저장 기준은 항상 원문 텍스트다.
- [ ] 렌더 모드는 원문을 보기 좋게 표현하되 임의로 재작성하지 않는다.
- [ ] 줄바꿈, 들여쓰기, 공백, 따옴표, 주석, 키 순서, 구분자를 가능한 한 보존한다.
- [ ] 큰 파일 열기, 입력, 스크롤, 모드 전환이 느려지지 않아야 한다.
- [ ] 외부 요청, 스크립트 실행, 수식 주입처럼 파일 열람을 넘어서는 위험은 기본 제한한다.

## 현재 완료된 핵심 범위

- [x] Tauri 2 기반 데스크톱 앱 셸.
- [x] 텍스트 계열 파일 열기, 저장, 다른 이름으로 저장.
- [x] 메모장형 메뉴와 상태 표시줄.
- [x] 파일별 탭 열기, 새 탭 추가, 탭별 닫기.
- [x] `.txt` 원문 모드 편집.
- [x] 렌더 모드 줄 번호, 구문 강조, 들여쓰기 가이드.
- [x] 렌더 모드 가상화 표시.
- [x] 라이트/다크/시스템 테마와 테마별 렌더 모드 색상 설정.
- [x] 독립 설정창 표시와 숨김 권한 구성.
- [x] 변경된 파일을 닫기 전 저장 여부 확인.
- [x] Windows 가로 휠 입력 보정.
- [x] Windows 릴리스 빌드.

## 남은 기능

- [ ] 검색, 바꾸기, 특정 줄 이동.
- [ ] 저장 대화상자의 확장자 필터를 열기 대화상자 범위와 맞추기.
- [ ] 앱 표시 이름과 번들 실행 파일 이름을 `text-pad`로 정리.
- [ ] 이전 인페이지 설정 모달 상태와 CSS 제거.
- [ ] 사용하지 않는 Rust 예제 명령 제거.
- [ ] 외부 파일 변경 충돌 감지.
- [ ] 파일 인코딩 감지와 보존.
- [ ] 줄바꿈 형식 감지와 보존.
- [ ] 큰 파일 경고 또는 읽기 전용 모드.
- [ ] Markdown 렌더링과 안전한 부분 편집.
- [ ] JSON 트리 보기와 값 편집.
- [ ] CSV/TSV 표 보기와 셀 편집.
- [ ] CSV 수식 주입 위험 감지.
- [ ] YAML 구조 보기와 주석 보존형 편집.
- [ ] macOS와 Linux 빌드 검증.

## 완료 기준

- [ ] 저장 후 다시 열어도 사용자가 의도하지 않은 포맷 변경이 없다.
- [ ] 렌더 모드 편집 결과가 원문에 안전하게 반영된다.
- [ ] 실패 상태에서도 원문 모드 편집과 저장을 계속할 수 있다.
- [ ] 새 기능은 `npm run check`를 통과한다.
- [ ] Tauri 설정, 권한, Rust 코드, 패키징에 영향이 있으면 `npm run tauri build`를 통과한다.
- [ ] UI 변경은 실제 화면에서 겹침, 잘림, 키보드 접근성을 확인한다.
